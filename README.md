Selection_MA contains scripts for the analyses that appear in Grosse-Sommer and Hadfield (2026). In [R/Eden_Model_SI.html](R/Eden_Model_SI.html) mutation accumulation experiments are simulated using the Eden model of colony growth. The efficiency of selection is compared to that under homogenous growth using inference methods for estimating the distribution of fitness effects from mutations subject to selection bias. Finally, a meta-analysis of microbial mutational patterns is conducted to quantify the deficit of non-synonymous mutations. The script [R/Ecoli_Data_SI.html](R/Ecoli_Data_SI.html) collates information about mutations from several wild-type *Escherichia coli* mutation accumulation studies, including our own (detailed in Grosse-Sommer, Newman and Hadfield (2026) and the GitHub repository [Ecoli_MA](https://github.com/jarrodhadfield/Ecoli_MA)). These data are analysed using a multinomial model detailed in [R/Multinimomial_Model_SI.html](R/Multinimomial_Model_SI.html). We do not provide the supplementary files of the publications from which the mutational data were obtained, but the file [/Data/Raw/all_mutations.csv](/Data/Raw/all_mutations.csv) summarises these data. Note that in this file all mutational positions are with respect to the NC_000913.3 reference.
